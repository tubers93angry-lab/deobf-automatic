# 🔓 Auto Deobfuscator

> **An automatic Lua/Luau deobfuscator that has just begun development.**

**Auto Deobfuscator** is a newly started project focused on automatically detecting and deobfuscating different Lua/Luau obfuscation methods.

The project is still in its early stages, but development has already started.

## 🚧 Support Coming Soon

Over the next few days, we plan to add support for several popular obfuscators, including:

* **WeAreDevs**
* **LuaObfuscator**

  * Support for different obfuscation types
  * Automatic detection of supported protections
* **MoonSec V4**
* And eventually, **many other obfuscators and versions**

> ⚠️ Support for these obfuscators is still under development. Some scripts may not work perfectly in the first releases.

## 🧠 Automatic Deobfuscation

The main goal is to make deobfuscation as automatic as possible.

Instead of manually selecting an obfuscator, the system will analyze the input code, detect known patterns, identify the obfuscation being used, and attempt to apply the appropriate deobfuscation method.

```text
Lua/Luau Script
      ↓
Automatic Detection
      ↓
Obfuscator Identification
      ↓
Deobfuscation
      ↓
Reconstructed Code
```

## 🌐 Open Source

The entire project will be **open source**.

The deobfuscators, detectors, and other components developed for supported obfuscators will be publicly available, allowing developers and researchers to study, improve, and contribute to them.

The goal is to build an open project where different deobfuscation techniques can be shared and improved by the community.
